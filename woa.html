Pages: 1 rubric → 2 essay (no marks) + first score → 3 essay with suggestions + assistant (no free text) → 4 original essay again + second score → 5 thanks. The assistant opens by scoring the original essay 60/100 in every condition (the rubric score). WOA = (second score − first score) ÷ (60 − first score), both scores for the same original essay. Each good suggestion accepted adds 10 to the revised essay’s rubric score; each bad one costs 10 on Evidence. Timing is the same in every condition: 10 s “Thinking…” before the first message, then 1.2 s per reply. Human-like replies arrive as 2–3 short messages 0.9 s apart (the last asks “Do you want to accept this change?”); the machine sends the same content as one message after the same total wait.
